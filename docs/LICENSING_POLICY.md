- 프로젝트 자체 설명 문서·교재·슬라이드·강의 그림·설계 설명: **CC BY-NC 4.0**.
- 코드·실행용 설정·AI 작업 규칙/스킬·테스트: 기존 **Apache 2.0 준비 기준 유지**. 이번 합의만으로 코드까지 NC 적용을 확정하지 않습니다.
- 외부 자료·패키지·인용·캡처: 원래 조건과 표시를 유지하고 별도 허락·예외를 확인합니다.
- `.md`라는 확장자만으로 분류하지 않습니다. 실행용 `CLAUDE.md`·`SKILL.md`·AI 명령과 설명 문서를 구분합니다.

- **비상업적 이용:** 주로 상업적 이익이나 금전적 보상을 의도하거나 지향하지 않는 이용을 뜻합니다. 학교·비영리기관이라는 이름만으로 판단하지 않습니다.

1. [현재 기준 파일 확인대장](rights-review-current.csv)의 파일 경로·blob SHA와 실제 공개 후보를 대조합니다. 대장의 기준은 현재 준비 작업의 시작 main이며, 새 정책 파일까지 모두 포함한 최종 배포 명세는 아닙니다.
