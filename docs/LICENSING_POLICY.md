# 라이선스 적용 정책 — 교육자료 CC BY-NC 4.0

## 확정된 방향과 적용 범위

2026-10-29 윤성열(Andy)이 회의에서 **CC BY-NC로 합의되었다고 전달하고 적용·공개 준비를 요청**했습니다. 기존 논의의 4.0 국제 버전을 기준으로, 교육자료의 정책을 CC BY 4.0 준비안에서 **CC BY-NC 4.0**으로 변경합니다. 2026-10-29는 합의 전달·기록일이며 회의 개최일의 별도 증빙은 아닙니다.

- 프로젝트 자체 설명 문서·교재·슬라이드·강의 그림·설계 설명: **CC BY-NC 4.0**.
- 코드·실행용 설정·AI 작업 규칙/스킬·테스트: **Apache License 2.0으로 분리 적용(선택·확정된 정책)**. 코드까지 NC를 적용하는 선택은 하지 않았습니다. 정책 선택과 실제 권리자의 자료별 허락·귀속·고지 확인은 별개입니다.
- 외부 자료·패키지·인용·캡처: 원래 조건과 표시를 유지하고 별도 허락·예외를 확인합니다.
- `.md`라는 확장자만으로 분류하지 않습니다. 실행용 `CLAUDE.md`·`SKILL.md`·AI 명령과 설명 문서를 구분합니다.

[루트 LICENSE](../LICENSE)는 위 적용 정책과 범위를 안내합니다. **라이선스 선택은 합의됨 / 자료별 허락·노출 검수는 확인 필요 / 실제 외부 공개는 미실행**으로 구분합니다. 합의 전달을 무시하고 정책 선택을 다시 미정으로 돌리지 않되, 파일별 확인 상태를 일괄 완료로 바꾸지도 않습니다.

## 이용자에게 설명할 내용

- **비상업적 이용:** 주로 상업적 이익이나 금전적 보상을 의도하거나 지향하지 않는 이용을 뜻합니다. 학교·비영리기관이라는 이름만으로 판단하지 않습니다.
- **복제·공유·수정:** 비상업적 이용 범위에서 공식 원문의 조건에 따라 가능합니다.
- **표시:** 제공된 저작자·저작권·라이선스·면책 고지 등을 유지하고, 라이선스 링크와 수정 여부·기존 변경 표시를 적절히 표시합니다.
- **상업적 이용:** 이 라이선스가 허용하는 범위 밖의 상업적 이용은 해당 권리자의 별도 허락을 확인합니다. 프로젝트 운영자가 모든 외부 자료의 허락을 대신할 수 없습니다.
- **SA 조건 없음:** CC BY-NC는 BY-NC-SA가 아닙니다. 수정본에 동일 라이선스를 적용할 의무를 추가하지 않습니다. 다만 원자료의 NC·표시 조건과 이용자에게 주어진 권리를 우회하거나 제한할 수 없습니다.
- **저작권 예외·제한:** 법령상 허용되는 이용에 라이선스 조건을 추가로 강요하지 않습니다.

이 설명은 원문의 요약입니다. 개별 계약·이용의 법적 판정을 대신하지 않습니다. NC가 적용되는 교육자료 공개를 상업적 이용까지 자유로운 소프트웨어 오픈소스 라이선스와 동일하게 표현하지 않습니다.

## 파일별 적용 절차

1. [현재 317개 배포 기준 명세](distribution-manifest-d698f205.csv)의 경로·blob SHA·SHA-256을 기준 `d698f2055d40c0dfb76f26716d422a6e9c5b4e3f`와 대조합니다. 과거 [326행 대장](rights-review-current.csv)은 역사로 보존합니다. 새 명세는 기준 커밋의 스냅샷이며 이 수정안 추가분·최종 배포판 전체 검수 증명은 아닙니다.
2. 권리자·원출처·기여 범위와 선택된 교재 CC BY-NC 4.0 / 코드 Apache 2.0의 해당 적용 허락 또는 제3자 원 라이선스 근거를 특정합니다. 회의 합의로 이미 확인된 범위가 있으면 그 비민감 근거를 연결하고, 같은 동의를 중복 요청하지 않습니다.
3. 외부 자료·코드·기관 제공 자료는 예외를 구분합니다. RFP 또는 그 내용을 파생한 예제는 이름을 가린 것만으로 허락 완료라고 보지 않습니다.
4. 개인정보·고객정보·비밀·PDF/Office의 메타데이터와 화면 캡처를 확인합니다. 현재 파일뿐 아니라 공개될 과거 이력·다른 브랜치·첨부도 별도 확인합니다.
5. 허락과 검수가 확인된 파일에 저작자·라이선스·원본·변경·예외 고지를 반영합니다. [표시 양식](ATTRIBUTION_TEMPLATE.md)을 사용하되 미확인 저작권자를 추정해 채우지 않습니다.
6. 최종 배포 SHA와 예외 목록을 확인한 뒤 공개 승인을 받습니다. 이번 준비에서 저장소 visibility는 변경하지 않습니다.
