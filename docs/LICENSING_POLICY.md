# 라이선스 준비 정책 — 선택은 완료, 자료별 허락은 별도 확인

2026-10-08 · 운영자가 정할 준비 기준을 위임받아 **Apache 2.0 + CC BY 4.0**으로 정합니다. 전체 자료에 배포 허락을 부여하는 문서가 아닙니다. 현재 [LICENSE](../LICENSE)는 예정 안내이며 정식 적용 선언으로 바꾸지 않았습니다.

## 분류 기준

- 코드·실행용 설정·AI 작업 규칙/스킬·테스트: Apache 2.0을 기준으로 준비.
- 설명 문서·교재·강의 그림·설계 설명: CC BY 4.0을 기준으로 준비.
- 외부 자료·패키지·인용·캡처: 원출처의 조건을 우선 확인. 위 두 라이선스로 임의 재지정하지 않음.
- `.md`라는 확장자만으로 분류하지 않음. `CLAUDE.md`, `SKILL.md`, AI 명령처럼 실행용 문서와 설명용 문서를 구분.

## 실제 적용 전에 필요한 확인

1. 자료를 특정하고 실제 권리자와 배포 허락을 확인합니다. 작성자 이름이나 Git 커밋 권한만으로 기관·회사 권리를 추정하지 않습니다.
2. 출처·원 라이선스·변경 여부·필요한 표시와 외부 자료 예외를 기록합니다.
3. 코드의 저작권·라이선스·해당 NOTICE 표시, 교재의 적절한 출처·라이선스·변경 표시 등 실제 의무를 확인합니다.
4. 허락을 확인한 자료에만 적용 선언을 반영하고, 불명확한 자료는 해결하거나 제거·대체한 뒤 공개합니다.

CC BY 4.0은 조건을 지키는 수정·재배포·상업적 이용을 허용합니다. Apache 2.0도 재배포 고지 등 조건이 있으며 기여 범위와 관련된 명시적 특허 허락 조항이 있습니다. 두 라이선스 모두 다른 사람의 개인정보·상표·외부 자료에 대한 권리를 대신 부여하지 않습니다. 실제 판단은 원문과 해당 자료의 권리 상태에 따릅니다.
