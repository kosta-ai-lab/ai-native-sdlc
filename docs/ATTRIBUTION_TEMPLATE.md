# 교육자료의 저작자·라이선스 표시 양식

권리자와 적용 범위 확인이 끝난 자료에 사용하는 양식입니다. 아래 대괄호는 실제 확인한 값으로 채우고, 빈칸을 남긴 상태로 적용 완료라고 기록하지 않습니다.

```text
자료명: [자료명과 버전]
저작자/저작권자: [확인된 저작자·저작권자와 제공된 고지]
원본: [원본 위치 또는 식별 가능한 출처]
라이선스: Creative Commons Attribution-NonCommercial 4.0 International
          (CC BY-NC 4.0 / 저작자표시-비영리 4.0 국제)
라이선스 안내: https://creativecommons.org/licenses/by-nc/4.0/
변경 사항: [변경 여부와 내용, 기존 변경 표시 유지]
별도 조건·제외 항목: [외부 이미지·인용·코드 등 해당 항목과 원 조건]
```

- 비상업적 이용 범위에서 공유·수정할 수 있으며, 세부 조건은 공식 전문을 따릅니다.
- 상업적 이용은 해당 권리자의 별도 허락을 확인합니다. 운영자 문의가 자동 허락을 뜻하지 않습니다.
- SA(동일조건변경허락)를 추가하거나 수정본의 원저자 제출을 의무화하지 않습니다.
- 원저자·기관이 이용자의 활동을 보증하거나 승인한 것처럼 표시하지 않습니다.
- 코드와 외부 자료에는 이 양식을 기계적으로 덮어쓰지 않습니다.
