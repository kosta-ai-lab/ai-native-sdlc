| 완성도 | 모든 모듈을 완성할 때까지 기다리지 않습니다. 초안·작성 예정·실험 자료를 구분하고, 확인한 실행 범위와 한계를 표시합니다. |
| 라이선스 준비 기준 | 코드·실행용 설정/스킬은 Apache 2.0, 설명 문서·교재·그림은 CC BY 4.0을 기준으로 준비합니다. 실제 배포 허락과 적용은 자료별 권리 확인 뒤 진행합니다. |
| 초기 운영·공개 총괄 | 윤성열(Andy), GitHub `existmaster`. 다른 사람의 모듈 담당 수락을 임의로 확정하지 않습니다. |

| 일반 변경 검토 | 작성자 외 검토 1인 후 메인테이너가 반영합니다. 의미·권리·실행 동작을 바꾸지 않는 오탈자/링크 수정은 메인테이너 자체 확인으로 처리할 수 있습니다. |

## 꼭 필요한 확인만 남김

1. **기존 기여자·실제 권리자의 공개 허락**: 자료와 적용 조건을 특정해 확인합니다. 회사·기관·외부 자료 권리도 포함합니다.
2. **자료별 내용·노출 검수 결과**: 자동 검사의 미발견은 검수 완료가 아닙니다. [권리·자료 확인표](RIGHTS_REVIEW.md)에 확인 결과를 남깁니다.
3. **검수 결과에 따른 최종 공개 승인**: 최종 대상 SHA·남은 예외·필수 안내를 확인한 뒤 Andy가 실제 공개를 승인합니다. 이 준비 요청만으로 visibility를 바꾸지 않습니다.

누가 연락을 받을지, 어떤 리뷰 규칙을 쓸지, DCO/CLA를 도입할지 등을 다시 공동 미결정사항으로 올리지 않습니다. 다만 다른 사람의 권리를 처분하거나 작업 수락을 대신할 수는 없습니다.

## 실제 설정 상태

- 저장소: PRIVATE 유지, main 미변경.
- 현재 비공개 저장소의 main 보호 조회는 플랜 제한 오류를 반환했습니다. 유료 업그레이드는 수행하지 않습니다.
- CODEOWNERS는 준비 파일이며, 이 브랜치의 존재만으로 main의 검토 강제가 활성화되지는 않습니다.
- GitHub 비공개 취약점 신고는 현재 활성화를 확인하지 못했습니다(조회 404). 공개 후 활성화와 신고 버튼 표시를 확인합니다. 그전에는 위 비공개 이메일 요약 경로를 안내합니다.
