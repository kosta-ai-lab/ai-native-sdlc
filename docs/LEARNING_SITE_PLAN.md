# AI-Native SDLC 학습 사이트 — 첫 시안

## 목표와 범위

GitHub 자료를 처음 접하는 개발자가 개발 전 과정의 흐름을 보고, 자신의 목적에 맞는 교재와 실습으로 이동할 수 있게 한다. 이 문서는 구현 계획이며 완료 보고가 아니다.

- 공개 저장소: `kosta-ai-lab/ai-native-sdlc`
- 별도 브랜치와 Draft PR에서 제작·검토한다. 이 PR의 생성은 main 병합 또는 사이트 배포를 뜻하지 않는다.
- 목표 호스팅: GitHub Pages. 별도 서버·회원가입·유료 서비스 없이 작동하는 정적 사이트.
- 첫 시안: 개발 과정 지도, 단계별 자료 패널, 목적별 추천 경로, 기존 강의 탐색, 기여 안내.
- 기존 모듈·강의 원본과 담당자·초안 상태를 보존한다. 공개 저장소의 실제 자료만 연결하며, 없는 실습을 완료된 과정처럼 표시하지 않는다.

## 방문자의 흐름

1. 첫 화면에서 AI와 개발할 때도 요구사항·설계·검증이 필요한 이유와 전체 흐름을 이해한다.
2. 학습 지도에서 단계를 선택해 필요한 개념, 확인할 결과물, 관련 원본 자료를 읽는다.
3. 대표 학습 경로를 따라 기존 자료로 이동한다. 안내를 읽은 상태와 실제 실습 완료를 혼동하지 않는다.
4. 강의별 탐색으로 개별 강사의 자료를 찾거나 GitHub에서 개선을 제안한다.

## 디자인 방향

- 분위기: 명료함, 전문성, 탐색의 즐거움.
- 중심 표현: 개발 단계들이 연결되고 선택한 단계가 강조되는 학습 지도.
- MotionSites 보유 스킬의 구성·타이포그래피·모션 기법을 참고하되 기존 브랜드·이미지·정확한 레이아웃을 복제하지 않는다.
- 장식용 영상보다 지도·연결선·정보의 전환에 모션을 사용한다.
- 모바일에서는 세로 흐름으로 전환하고, 키보드 탐색·명확한 포커스·동작 줄이기 설정을 지원한다.
- 문장은 자연스러운 한국어로 작성한다. 가짜 통계·학습자 수·완료 시간·검증 실적은 넣지 않는다.

## 구현과 배포 원칙

- `site/` 안에 정적 사이트를 구성한다. 기술 선택은 단순성과 유지보수를 우선한다.
- 기존 교재를 별도 복제하지 않고 GitHub 원본으로 연결한다. 링크와 표시 상태의 근거를 기록한다.
- Pages 프로젝트 하위 경로(`/ai-native-sdlc/`)에서 CSS·JavaScript·내부 탐색이 정상 작동해야 한다.
- 배포 산출물은 사이트 파일만 포함한다. 저장소 전체·감사 자료·개인 자료를 배포하지 않는다.
- PR에서는 정적 검증만 수행하고 배포하지 않는다. main 병합 이후의 배포 워크플로와 설정 절차를 마련한다.
- Pages 활성화·main 병합·첫 실서비스 배포는 시안 검토 후 별도 진행한다.
- 라이선스는 저장소의 교육자료 CC BY-NC 4.0 / 코드 Apache 2.0 구분과 제3자 예외를 유지한다.

## 완료 기준

- 실제 원본 자료에 연결되는 학습 지도와 강의 탐색이 동작한다.
- 데스크톱·모바일에서 화면을 렌더하고 직접 확인한다.
- 지도 선택, 경로 선택, 내부 이동, 키보드 탐색, 동작 줄이기, 프로젝트 하위 경로를 실제 시험한다.
- 모든 원본 자료 경로가 Git 추적 파일에 존재하며 초안·준비 중 상태를 과장하지 않는다.
- 민감 정보·비공개 자료·불필요한 대용량 파일이 추가되지 않았음을 변경분에서 확인한다.
- Draft PR, 실제 열람 가능한 미리보기, 실행한 검사 결과와 미검증 범위를 전달한다.
