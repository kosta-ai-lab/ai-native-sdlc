# ADR 0002 — 오픈코어 + 비공개 인큐베이션으로 시작

- 상태: Accepted
- 날짜: 2026-06-04

## 맥락

공개 방식을 정해야 한다. 완전 오픈, 오픈코어, 회원 전용 중에서, 확산(브랜드)과 지속(수익)을 함께 가져갈 모델이 필요하다. 또한 초기 품질이 갖춰지기 전 미완성 상태를 노출하지 않아야 한다.

## 결정

**오픈코어**로 한다. 코어 방법론·기본 패턴은 공개하고, 심화 패턴·인증·컨설팅은 회원·유료로 한다. 시작은 **비공개(private) 인큐베이션**이며, 전환 기준을 충족하면 코어를 공개한다.

## 근거

- 완전 오픈은 확산은 크나 직접 수익이 약하고, 회원 전용은 커뮤니티 명분이 약하다. 오픈코어가 균형점이다.
- 비공개 시작은 미완성 노출과 경쟁 노출을 막고, 공개 시점을 런칭 이벤트로 만들 수 있다.

## 결과

- 공개 전환 기준: 코어 모듈 5~6개 + 동작 레퍼런스 앱 1개 + "따라 하면 되는" 문서.
- 코어와 프리미엄(회원)의 경계를 처음부터 설계한다.
