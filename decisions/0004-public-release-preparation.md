# ADR 0004 — 전체 저장소 공개 준비와 초기 운영 기준

- 날짜: 2026-10-08
- 상태: 메인테이너 위임에 따른 **준비 기준 선택 완료**. 준비 브랜치 반영 / main 적용·공개 전환 대기.
- 결정 책임: 윤성열(Andy)
- 관계: [ADR 0002](0002-open-core-private-start.md)의 오픈코어·비공개 인큐베이션 기록은 역사로 보존하고, 이번 준비 방향은 아래 기준을 사용합니다.

## 배경

저장소에는 교육 과정·PDF·실습 코드가 있고, 전주기 방법론은 작성 예정인 단계가 섞여 있습니다. 기존 문서는 일부 공개와 모듈 완성 수를 전제합니다. 메인테이너는 일반 대중에게 전체를 공개하는 방향을 지정하고 운영자가 정할 기준의 처리를 위임했습니다.

## 정한 내용

1. 전체 저장소 공개를 목표로 준비하고 미완성 자료는 상태를 표시합니다. 완성과 배포 권리·안전을 혼동하지 않습니다.
2. 코드·실행용 자료는 Apache 2.0, 설명·교재는 CC BY 4.0으로 공개할 준비를 합니다. 기존 자료를 무단 재라이선스하지 않습니다.
3. 초기 운영 총괄은 Andy. 일반 변경은 작성자 외 검토 1인 후 메인테이너가 반영합니다. 낮은 위험의 오탈자·링크 변경은 자체 확인할 수 있습니다.
4. 기여 출처·권한은 PR 질문으로 확인합니다. 초기 DCO·CLA 의무는 도입하지 않습니다.
5. 내부 목표는 2026-10-14 자료 확인, 2026-10-16 조건부 공개입니다. 권리·안전 문제가 남으면 조정합니다.

## 결정하지 않았거나 대신할 수 없는 것

- 타인의 공개·배포 허락, 회사·기관·외부 자료의 권리 승인
- 아직 수행하지 않은 자료별 내용 검수와 외부 도구·유료 API의 전체 실행 인증
- main 병합, 공개 설정 변경, 유료 요금제 변경, 다른 사람의 작업 수락
