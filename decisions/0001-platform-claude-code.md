# ADR 0001 — 플랫폼을 Claude Code로 통일

- 상태: Accepted
- 날짜: 2026-06-04

## 맥락

자산(스킬·훅·서브에이전트·샘플)을 서로 붙여 쓰고 함께 확산하려면 에이전트 코딩 플랫폼을 하나로 통일해야 한다. 후보는 Claude Code, Codex CLI, Cursor 등이다.

## 결정

표준 플랫폼을 **Claude Code**로 한다.

## 근거

- 코딩 전문성이 가장 높고, 스킬·훅·서브에이전트·플러그인 생태계가 갖춰져 있다.
- 자산이 포터블해, 표준을 정해도 추후 다른 도구로 옮길 수 있다.
- Cursor 등 IDE는 인수합병 등 지속성 리스크가 있어 표준으로는 보류한다. Codex는 후보군으로 병행 검토한다.

## 결과

- 모든 실행 자산은 Claude Code 규격으로 작성한다.
- 도구 종속을 줄이기 위해, 방법론·명세는 도구 중립으로 기술하고 도구 바인딩은 분리한다.
