# ADR 0005 — 교육자료 공개 라이선스 CC BY-NC 4.0

- 상태: 라이선스 선택 합의 반영. 자료별 적용 확인·main 병합·외부 공개는 별도.
- 기록일: 2026-10-29. 합의 전달일이며 실제 회의일을 새로 단정하지 않음.
- 근거: 프로젝트 주도자 윤성열(Andy)이 회의에서 CC BY-NC로 합의되었다고 전달하고 해당 라이선스를 적용한 공개 준비를 요청함.
- 대체 범위: [ADR 0004](0004-public-release-preparation.md)의 교육자료 CC BY 준비 기준. 나머지 전체 공개 방향·운영 기준은 유지.

## 결정

프로젝트 자체 교육자료·설명 문서·교재·슬라이드·강의 그림은 기존 논의의 **CC BY-NC 4.0 국제**를 적용하는 방향으로 공개 준비한다. 이전 CC BY 추천·준비안을 현재 선택으로 사용하지 않는다.

이번 합의를 코드·실행용 설정/스킬의 NC 전환까지 확장하지 않는다. 기존 Apache 2.0 준비 기준은 유지하며, 외부 자료의 이용 조건과 과거 유효하게 부여된 라이선스는 변경하지 않는다.

## 반영

루트 LICENSE, README, 적용 정책, 공식 전문·해시, 표시 양식, 최신 파일 확인대장, 공개 준비 현황에 반영한다. 기존 ADR·과거 CSV·검증 기록은 역사로 보존한다. 라이선스 방향을 다시 묻는 선호 설문은 선행조건으로 두지 않는다.

## 남은 확인

- 이미 합의로 허락된 자료의 구체 범위를 확인해 대장에 연결하고, 필요한 추가 허락만 확인한다.
- 개인정보·기밀·외부 자료·과거 이력·브랜치·첨부를 점검한다.
- 허락을 확인한 실제 배포 파일에 고지를 적용하고 최종 SHA와 예외를 확정한다.
- 별도의 최종 공개 승인 전에는 저장소를 PRIVATE로 유지한다.
