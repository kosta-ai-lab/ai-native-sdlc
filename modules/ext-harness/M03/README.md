# 모듈 — — 기존에 만들어진 하네스 활용

> 상태: 초안 · 담당: 이선아 교수

## 목적

참조 깃허브 링크에서 기존에 만들어진 하네스를 활용하는 법을 배운다. .claude 폴더에 기존에 만들어진 에이전트와 스킬을 복사하여 Claude Code를 활용한 실습을 진행한다.

## 산출물 4종 (체크리스트)

- [x] 가이드 — GUIDE.md 단계 목적·입력·산출물·체크리스트
- [X] 규칙 — CLAUDE.md 조각은 .claude 폴더 하에 존재하며 하네스의 구성 에이전트와 스킬 나열
- [x] 자동화 — .claude 폴더 하에 존재하는 스킬과 에이전트 존재
- [x] 샘플 — SAMPLE.md 동작 스텝·프롬프트

## 품질 기준

동작하는 샘플 또는 재현 가능한 프롬프트가 반드시 첨부되어야 하며, 문서는 따라 하면 되는 수준이어야 한다.

- 가이드에서는 이론적인 내용을 포함하여 개념과 따라가기가 함께 되는 수준이어야 한다.
- 샘플은 가이드에서 만든 결과를 활용할 수 있는 재현 가능한 프롬프트가 반드시 첨부되어야 하며, 따라 하면 되는 수준이어야 한다.
- 자동화는 활용 폴더에 이미 올려 둔다.
