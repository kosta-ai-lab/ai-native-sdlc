# 모듈 — Jev 게임 에이전트 2 — 격자 미로 탈출

> 상태: 초안 · 담당: 이선아 교수

## 목적

왼쪽 아래에서 출발해 오른쪽 위 출구로 나가는 **격자 미로 탈출 게임**을 순수 Python으로 만든다. 같은 게임 환경에 **무작위 → 규칙 기반 → 탐색 알고리즘 → Jev** 정책을 차례로 꽂아 보며 AI 에이전트의 기본 구성 요소를 익히고, **Jev를 미로 탈출 정책으로 쓰는 방법**을 단계적으로 다듬는다. 마지막에는 "지도 전체를 보는 Jev"와 "주변만 보는 Jev"를 비교해, 센서로만 주변을 아는 드론 상황으로 넘어갈 준비를 한다.

> 선수 모듈: [M03-grid-agent](../M03-grid-agent/README.md) (결정 루프, state 설계, 안전 감시)

## 미로 탈출 게임이란

엄밀히 말하면 상대방 없이 미로를 탈출하는 게임은 **단일 에이전트의 순차적 의사결정 문제**다. 에이전트가 한 턴에 한 번 행동하고, 그 결과로 다음 상황이 정해진다. 적이나 다른 플레이어가 번갈아 움직이도록 구성하면 **다중 에이전트 턴제 게임**이 된다 (이 모듈의 확장 과제).

```
    0 1 2 3 4
  0 . . . # G     ← 출구 (0, 4): 오른쪽 위
  1 . # . # .
  2 . # . # .
  3 . # . . .
  4 A # . # .     ← 시작 (4, 0): 왼쪽 아래
```

## 에이전트 설계 7요소

| 구성 요소 | 설명 | 이 모듈의 코드 |
|---|---|---|
| **Environment** (환경) | 2차원 격자 미로 | `env.py`의 `MazeEnv` |
| **State** (상태) | 에이전트의 현재 위치와 미로 상태 | `env.state` = (행, 열), `env.maze` |
| **Action** (행동) | 상, 하, 좌, 우 이동 | `ACTIONS = {"UP", "DOWN", "LEFT", "RIGHT"}` |
| **Goal** (목표) | 출구 도착 | `env.goal` = 오른쪽 위 |
| **Reward** (보상) | 출구 도착 +100, 이동 -1, 장애물 충돌 -10 | `env.step()`이 돌려줌 |
| **Policy** (정책) | 다음 이동 방향을 결정하는 전략 | `agents.py`의 에이전트들 |
| **Termination** (종료) | 출구 도착 또는 최대 턴 초과 | `env.done`, `env.reason` |

**환경과 에이전트를 분리**하는 것이 핵심 설계다. 환경(`env.py`)은 규칙과 보상만 알고 누가 움직이는지 모른다. 에이전트(`agents.py`)는 `act(env)` 하나만 구현하면 된다. 그래서 사람, 규칙, BFS, Jev를 **코드 수정 없이 갈아 끼울 수 있다**. 드론에서도 시뮬레이터와 실제 기체를 같은 방식으로 갈아 끼운다.

```python
state = env.reset()
while not env.done:
    action = agent.act(env)                          # 정책이 행동을 고름
    state, reward, done, info = env.step(action)     # 환경이 결과와 보상을 돌려줌
```

## 정책 비교

| 정책 | 방식 | 미리 알아야 하는 것 | 장점 | 한계 |
|---|---|---|---|---|
| **무작위** | 아무 방향이나 | 없음 | 비교 기준(하한선) | 거의 탈출 못 함 |
| **규칙 기반** | 사람이 짠 규칙 (탐욕법, 우수법) | 없음 (주변만 봄) | 빠르고 예측 가능 | 규칙이 안 맞는 미로에서 실패하거나 돌아감 |
| **탐색 (BFS)** | 지도 전체에서 최단 경로 계산 | **지도 전체** | 항상 최단 경로 (만점) | 지도가 없거나 바뀌면 못 씀 |
| **Jev** | 지금 보이는 상황으로 바로 판단 | 없음 (**학습도 필요 없음**) | 처음 보는 미로에서 바로 판단, 확률 제공 | 호출마다 지연·비용, 결과 검증 필요 |

### 규칙 기반 두 가지
- **탐욕법 (greedy)**: 출구와의 거리가 줄어드는 방향으로 간다. 단순하지만 **막다른 길**에서 같은 자리를 왕복한다.
- **우수법 (wall follower)**: 오른손을 벽에 대고 걷듯이 **오른쪽 → 앞 → 왼쪽 → 뒤** 순서로 갈 수 있는 첫 방향으로 간다. 벽이 모두 이어진 미로라면 언제나 탈출하지만 최단 경로는 아니다.

### 왜 강화학습 대신 Jev인가
미로 탈출은 보통 강화학습(Q-learning 등)의 첫 예제로 쓰인다. 하지만 강화학습은 **같은 미로를 수백 판 연습**해야 잘하게 되고, 미로가 바뀌면 처음부터 다시 배워야 한다. 실제 드론은 처음 가는 공간에서 수백 번 부딪혀 볼 수 없다.

Jev는 **연습 없이, 처음 보는 미로에서 지금 보이는 정보만으로** 판단한다 (System 1). 대신 판단의 질은 **무엇을 보여 주느냐(관측)**와 **어떤 선택지를 주느냐(마스킹)**에 달려 있다. 이 모듈은 이 두 가지를 다듬는 연습이다. 보상은 학습이 아니라 **모든 정책을 같은 기준으로 채점하는 점수표**로 쓴다.

## 핵심 개념 4가지 (M03에서 한 걸음 더)

### 1. 관측 범위: 전체 관측 vs 부분 관측
| 관측 | 무엇을 보여 주나 | 대응하는 실제 상황 |
|---|---|---|
| **full** (전체 관측) | 미로 전체 지도, 방문한 칸 목록 | 지도가 있는 실내 비행, 게임 |
| **local** (부분 관측) | 주변 3×3, 상하좌우 칸 종류와 **방문 횟수**, 출구 방향 | **센서만 있는 드론** (카메라·거리 센서) |

부분 관측에서는 지도가 없으므로 **짧은 기억(방문 횟수)**이 막다른 길을 벗어나는 열쇠가 된다. "가 본 적 없는 쪽을 먼저"라는 판단을 Jev에게 맡긴다.

### 2. 행동 마스킹 (Action Masking)
M03에서는 Jev가 막힌 칸을 고르면 **안전 감시가 나중에 바꿨다**. 이 모듈에서는 한 걸음 앞서, **갈 수 있는 방향만 선택지로 준다**.

```python
options = env.valid_actions()                      # 예: ["UP", "RIGHT"]
Choice(instructions=..., criteria={a: ACTION_TEXT[a] for a in options})
```

Choice의 선택지는 **호출할 때마다 바꿀 수 있다**. 그래서 충돌이 원천적으로 사라진다. 갈 곳이 하나뿐이면 Jev를 부르지 않아 호출 수와 지연 시간도 줄어든다. 드론에서는 "지금 상태에서 허용된 명령만" 선택지로 주는 방식이다 (예: 착륙 중에는 `goto`를 빼기).

| 방식 | 언제 막나 | 장점 | 주의 |
|---|---|---|---|
| 안전 감시 (M03) | Jev가 고른 **뒤**에 교체 | Jev가 무엇을 원했는지 로그에 남음 | 교체가 잦으면 Jev가 상황을 잘못 보는 것 |
| 행동 마스킹 (M05) | Jev가 고르기 **전**에 선택지에서 제외 | 충돌 0, 호출 수 감소 | 마스킹 규칙 자체가 틀리면 막을 수 없음 |

실전에서는 **둘 다** 쓴다. 마스킹으로 기본을 거르고, 안전 감시로 마지막을 지킨다.

### 3. 확률 기반 대체 정책 (Fallback)
Jev는 답과 함께 **확률**을 준다. 고른 행동의 확률이 낮다는 것은 "Jev도 확신하지 못한다"는 뜻이다. 이때 **검증된 규칙(우수법)으로 대신 움직이게** 할 수 있다.

```python
if jev_가_고른_행동의_확률 < 0.6:
    action = 우수법.act(env)        # 애매할 때는 확실한 규칙으로
```

| Jev 확률 | 행동 |
|---|---|
| 높음 (≥ 0.6) | Jev의 판단대로 (빠르고 똑똑하게) |
| 낮음 (< 0.6) | 우수법으로 대체 (느리지만 반드시 탈출) |

M01의 "확신이 높으면 자동 처리, 애매하면 사람에게"를 **"애매하면 규칙에게"**로 바꾼 것이다. 드론에서는 "판단이 애매하면 제자리 비행(hold)하거나 이미 검증된 경로로 복귀"에 해당한다.

### 4. 보상으로 정책 채점하기
보상은 **모든 정책을 같은 기준으로 채점하는 점수표**다. 7단계 비교표에서 "탈출했는가"뿐 아니라 "몇 번 만에, 몇 번 부딪히며"를 보상 하나로 비교한다. 각 미로의 만점은 BFS의 점수다.
