# 실습 원요청 — 개인용 할 일 관리 웹 앱

혼자 쓰는 간단한 할 일 관리 웹 앱이 필요합니다. 할 일을 입력해서 목록에 추가하고, 끝낸 일은 완료 표시를 하거나 다시 미완료로 돌릴 수 있으면 좋겠습니다. 필요 없는 일은 삭제하고 싶습니다.

전체·진행 중·완료 목록을 선택해서 보고, 아직 끝내지 않은 일이 몇 개인지 알고 싶습니다. 여기서 ‘진행 중’은 별도 업무 상태가 아니라 완료하지 않은 항목을 뜻합니다. 새로 고치거나 브라우저를 닫았다 열어도 목록이 남아 있어야 합니다.

로그인이나 여러 사람의 공유 기능은 이번에 필요하지 않습니다. 할 일 내용은 외부 서버로 전송하지 않았으면 합니다. 키보드만으로도 추가·완료·삭제·필터 선택을 할 수 있어야 합니다. 화면과 안내는 한국어로 보여 주세요.

이 요청에는 입력 길이·중복·삭제 확인·저장 실패 처리 등이 아직 정해져 있지 않습니다. 실제 업무 자료가 아니라 요구사항 분석을 연습하기 위한 예제입니다.
