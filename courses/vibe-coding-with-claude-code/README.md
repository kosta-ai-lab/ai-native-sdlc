## 무엇을 얻어 가나

수료 시점에 **본인 이름으로 접속되는 Vercel URL**을 손에 쥡니다. 아이디어 하나를 골라 기획 → 설계 → 구현 → DB 연동 → 배포까지 하루에 완주합니다.

비개발자가 가장 크게 막히는 두 벽이 데이터 영속성과 배포입니다. 이 과정은 두 벽을 Supabase plugin과 Vercel plugin으로 넘습니다. plugin을 한 번 설치해 두면, 그다음부터는 자연어 한 줄로 DB가 붙고 공개 URL이 나옵니다.

## 학습 목표

1. 바이브 코딩의 개념과, 코딩을 모르는 사람이 어디까지 할 수 있는지 설명한다
2. Claude Code를 설치하고 자연어만으로 웹앱을 생성한다
3. 요구사항과 UX를 정리해 결과물의 품질을 끌어올린다
4. 디자인 시스템과 `CLAUDE.md`로 일관된 UI와 프로젝트 맥락을 만든다
5. Plan 모드와 Skills로 효율적으로 반복 개선한다
6. Supabase plugin·Vercel plugin으로 DB 연동과 배포를 자연어 한 줄로 처리한다
7. 완성한 앱을 실제 URL로 동료에게 시연한다
