# Claude Code Cloud App Development-Golf Scorecard

## 강의 개요
Claude Code Cloud를 이용해 Golf Scorecard 앱을 개발하는 Vibe Coding 실습 데모

## 항목	내용
- 제목: Claude Code Cloud App Development-Golf Scorecard
- 대상: 비개발자
- 선수 지식: 없음
- 학습 목표: 비개발자가 Claude Code Cloud를 이용해 간단한 앱을 비용 없이 개발해 휴대폰에서 바로 쓸 수 있도록 배포까지 할 수 있다
- 분량: 4시간
- 학습 방법: 온라인 자기 주도 학습

## 학습 내용
- Claude Code 클라우드 개발 환경 설치
- 요구 사항 정의: MVP 결정
- 기술 스택 선정 및 필요 도구 설치
- 화면 구성
- 프로젝트 생성·구현·실행·테스트·빌드
- 클라우드 배포

## 학습 결과물
- 휴대폰 브라우저에서 https://golf-scorecard-kohl-xi.vercel.app/ 페이지를 엽니다.
- 브라우저 메뉴에서 '홈 화면에 추가'를 누르면 아이콘이 생겨 앱처럼 바로 열 수 있습니다.
- 골퍼가 18홀 라운드를 하면서 홀별 타수를 휴대폰에 기록하고, 라운드가 끝나면 총합을 확인할 수 있는 간단한 앱입니다.
