# 03 Design

Research의 지식을 교육 가능한 수행 순서로 바꾸는 공간입니다. 기관과 무관한 표준설계만 이곳에 둡니다.

- `blueprint.md`: 최종 수행, 최종 평가, 관통 프로젝트와 거시 진행
- `units/`: 측정 가능한 수행 단위의 세부 설계
- `course-design-notes.md`: 아직 확정하지 않은 과정 설계안과 검증 과제
- `content-cards.md`: 원고와 활동을 만들 때 사용할 개념·사례 후보
- `activity-catalog.md`: 데모·실습 후보와 선택 기준

Design 완료는 목차가 존재하는 상태가 아닙니다. 각 Unit이 최종 평가에 왜 필요한지 설명할 수 있고, 수행목표·활동·평가와 사용 지식이 정렬된 상태입니다.
