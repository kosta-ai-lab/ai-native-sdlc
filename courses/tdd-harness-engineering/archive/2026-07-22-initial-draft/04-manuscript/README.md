# 장문형 학습 자료

`02-research/`가 조사 결과와 근거를 정리하고 `03-design/`이 학습 순서를 설계한다면, 이 폴더는 독자가 처음부터 순서대로 읽을 수 있는 자기완결적인 교재 원고를 제공합니다.

각 문서는 다음 원칙으로 작성합니다.

- 앞선 회의나 대화를 알지 못해도 이해할 수 있게 배경을 설명합니다.
- 용어를 처음 사용할 때 뜻과 범위를 명확히 정의합니다.
- 표와 목록은 본문 설명을 요약하는 용도로만 사용합니다.
- 명령과 코드는 실행 목적, 예상 결과, 해석 방법을 함께 기술합니다.
- 도구의 공식 주장, 소스에서 확인한 사실, 연구 결과와 저자의 해석을 구분합니다.
- 성공 사례뿐 아니라 실패 조건과 적용 한계도 함께 설명합니다.

사실, 프로젝트 측 주장, 분석과 교육 제안을 구분하고 각주를 작성하는 방법은
[`근거·인용 작성 규칙`](../harness/EVIDENCE-GUIDE.md)을 따릅니다.
