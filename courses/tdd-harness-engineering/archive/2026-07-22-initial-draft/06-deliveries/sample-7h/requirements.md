# Sample Delivery 요구 프로파일 — 7시간 과정

## 목적

표준 과정을 특정 납품 상황에 적용하는 샘플이다. 실제 기관 요구가 아니며 adaptation 구조를 검증하기 위한 가상 프로파일이다.

## 대상

- 경력 1~3년의 백엔드 개발자
- 단위 테스트 작성 경험은 있으나 TDD와 BDD 경험은 제한적
- AI 코딩 에이전트를 일상적으로 사용하기 시작한 단계

## 제약

- 총 교육시간: 7시간
- 언어: TypeScript
- 테스트 도구: Vitest
- 개인별 로컬 실습
- 외부 SaaS 연결 없이 실행 가능해야 함

## 요구 학습성과

- test-after와 TDD를 실행 증거로 구분한다.
- BDD example에서 단위·통합 테스트를 도출한다.
- 테스트 실패 시 완료를 차단하는 최소 gate를 구현한다.
- 실패 주입으로 gate의 fail-open 문제를 발견한다.

## 우선순위

개별 도구 설치법보다 다른 에이전트 환경에도 이전할 수 있는 원리와 실행 가능한 최소 하니스를 우선한다.
