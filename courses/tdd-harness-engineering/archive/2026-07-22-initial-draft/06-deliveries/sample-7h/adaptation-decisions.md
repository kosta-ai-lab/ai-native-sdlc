# Sample Delivery 변형 결정

## AD-01 — 유효한 Red 학습경험 압축

- 표준 학습경험: `U-02`, 35분
- 납품 배치: 25분
- 이유: 총 7시간 안에서 종합 하니스 프로젝트 시간을 확보해야 한다.
- 변경: 강사 주도 첫 사례를 사전 읽기로 이동한다.
- 유지: 세 가지 독립 판정, 세 조건의 근거 설명, 완료 기준
- 위험: 수강생의 초기 오개념을 수업 중 관찰할 시간이 감소한다.
- 완화: 시작 3분 익명 투표로 사전 판정을 다시 수집한다.

## AD-02 — TypeScript/Vitest 사례 사용

- 표준설계: 언어·프레임워크 중립
- 납품 변경: 모든 로그와 테스트 코드를 TypeScript/Vitest로 제공
- 이유: 대상자의 공통 실행 환경
- 유지: 실행 가능성, 관찰 타당성, 원인 일치라는 판정 모델
- 역병합 여부: 하지 않음. 코드는 delivery-specific courseware로 유지한다.

## 정렬 확인

시간과 기술 스택은 변경했지만 “세 사례를 정확히 판정하고 근거를 설명한다”는 표준 수행목표와 평가 기준은 변경하지 않았다.
