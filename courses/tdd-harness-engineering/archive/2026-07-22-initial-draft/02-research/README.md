# 02 Research

Planning에서 만든 질문에 답할 자료를 수집하고, 재사용 가능한 정보와 지식으로 가공하는 작업 공간입니다.

```text
inbox → wiki → synthesis
```

- `inbox/`: 아직 정식 지식으로 승격하지 않은 원문·소스 노트와 실험 기록
- `wiki/`: 도구나 개념별로 출처가 있는 정보를 정규화한 LLM Wiki
- `synthesis/`: 여러 Wiki·Source를 연결해 만든 원리, 절차와 판단 모델
- `sources.md`: 사람이 읽는 출처 목록과 조사 범위

Research 완료는 자료를 많이 모은 상태가 아닙니다. 핵심 조사 질문에 답할 근거가 있고, 다음 Design 단계가 사용할 수 있는 지식과 남은 불확실성이 구분된 상태입니다.
