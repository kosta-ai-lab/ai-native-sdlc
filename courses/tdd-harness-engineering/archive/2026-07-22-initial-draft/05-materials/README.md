# 강의 재료 모음

이 폴더는 승인된 Unit과 교재 원고를 실제 강의 설명, 데모, 실습과 평가로 투영한 자료를 모읍니다. 아직 설계 후보인 카드와 활동 카탈로그는 `03-design/`에 둡니다.

## 사용 방법

각 재료는 다음 흐름으로 사용합니다.

1. 개념을 한 문장으로 설명한다.
2. 개념이 없을 때 생기는 실패를 보여준다.
3. 실제 프로젝트나 도구가 이를 어떻게 구현하는지 확인한다.
4. 최소 구현을 직접 만든다.
5. 실패를 주입하여 정말 작동하는지 검증한다.
