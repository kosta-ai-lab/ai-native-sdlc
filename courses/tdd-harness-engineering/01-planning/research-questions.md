# 과정 조사 질문

## 문제와 대상

- 기존 TDD 교육과 에이전트 TDD 하니스 교육의 수행 차이는 무엇인가?
- 수강생이 이미 테스트를 작성할 수 있다고 가정할 수 있는가?
- 개발자, QA와 교육 담당자에게 같은 최종 프로젝트가 적합한가?

## 지식

- BDD example은 어떤 규칙으로 인수·통합·단위 테스트에 내려가는가?
- 올바른 Red를 기계적으로 판정하려면 어떤 증거가 필요한가?
- test-first 지침과 실제 상태 전이 차단은 어떤 통제층으로 나뉘는가?
- 신규 기능 TDD와 brownfield characterization workflow를 어떻게 구분하는가?

## 도구와 사례

- Superpowers, OpenSpec, Spec Kit, MoAI와 BMAD TEA에서 재사용할 원리는 무엇인가?
- 각 도구가 문서에서 주장하는 구조와 실제 실행 효과는 어디에서 달라지는가?
- 최소 하니스가 특정 도구에 종속되지 않으려면 어떤 interface가 필요한가?

## 학습 설계에 필요한 조사

- 최종 수행을 증명하는 최소 산출물과 실패 주입은 무엇인가?
- 4시간, 8시간과 16시간 과정에서 유지해야 할 핵심 수행은 무엇인가?
- 어떤 Unit이 개념형, 문제 진단형, 구현형 또는 설계 판단형이어야 하는가?
