# 단계별 진행 가이드

각 단계는 모든 질문을 의무적으로 묻지 않는다. `핵심 유도 질문` 중 기존 자료로 답할 수 없는 고가치 질문을 골라 한 번에 하나씩 사용한다.

## 01 Planning

### 이 단계에서 읽어야 할 의도

- 왜 지금 이 과정이 필요한가
- 누구의 어떤 수행을 바꾸려는가
- 과정이 성공했다는 증거는 무엇인가
- 표준 과정에서 의도적으로 다루지 않을 것은 무엇인가

### 핵심 유도 질문

1. 수강생이 과정 직후 현업에서 이전과 다르게 수행해야 하는 한 가지는 무엇인가?
2. 이 과정을 만들지 않으면 현재 어떤 문제가 계속되는가?
3. 개념을 설명하는 과정과 작동하는 결과물을 만드는 과정 중 어디에 무게를 둘 것인가?
4. 최종 결과물을 보고 수료 여부를 판정한다면 무엇을 보겠는가?
5. 이번 표준 과정에서 다루지 않기로 결정할 범위는 무엇인가?

### 산출물

- `brief.md`
- `research-questions.md`
- `intent.md`

### 전이 전 사용자 확인

문제, 대상, 최종 수행, 성공 증거와 제외 범위의 요약이 자신의 의도와 일치하는지 확인한다.

## 02 Research

### 이 단계에서 읽어야 할 의도

- 사용자가 이미 알고 있는 것과 검증하려는 것
- 권위 있는 근거가 필요한 주장
- 도구 조사와 원리 연구의 상대적 비중
- 실제 실험으로 확인해야 하는 불확실성

### 핵심 유도 질문

1. 이 과정에서 반드시 근거를 갖고 말해야 하는 핵심 주장은 무엇인가?
2. 사용법을 조사하려는가, 도구를 넘어서는 공통 원리를 찾으려는가?
3. 공식 문서의 설명만으로 충분하지 않고 직접 실행해야 하는 것은 무엇인가?
4. 조사 결과가 서로 충돌한다면 어떤 기준으로 채택할 것인가?
5. 어느 정도 근거가 모이면 조사를 멈추고 설계로 넘어갈 수 있는가?

### 산출물

- 조사 질문별 상태표
- source note와 Wiki
- 횡단 synthesis
- 미확인·실험 필요 목록

### 전이 전 사용자 확인

조사 결과가 처음 의도를 바꿨는지, 어떤 가설을 채택·폐기했는지 확인한다.

## 03 Design

### 이 단계에서 읽어야 할 의도

- 원하는 최종 수행의 깊이
- 과정의 서사와 난이도 상승 방식
- 설명, 진단, 구현과 설계 활동의 비중
- 표준으로 고정할 것과 납품에서 바꿀 수 있는 것

### 핵심 유도 질문

1. 최종 프로젝트를 먼저 본다면 어떤 하위 수행이 반드시 필요해 보이는가?
2. 수강생이 가장 먼저 버려야 할 오개념은 무엇인가?
3. 어떤 수행은 설명만으로 부족하고 직접 실패해 봐야 하는가?
4. 도구별 사례는 독립 Unit인가, 공통 원리를 설명하는 case인가?
5. 시간이 줄어도 절대 제거하면 안 되는 수행과 평가는 무엇인가?

### 산출물

- `blueprint.md`
- 지식·선수관계 지도
- `outline.md`
- Unit 설계와 평가 계약

### 전이 전 사용자 확인

목차 제목보다 최종 수행, Unit의 필요성과 전체 진행이 의도와 일치하는지 확인한다.

## 04 Manuscript

### 이 단계에서 읽어야 할 의도

- 교재가 독학용인지 강의 보조용인지
- 설명의 깊이와 독자의 배경지식
- 사례와 이론의 비중
- 사실·분석·제안의 목소리

### 핵심 유도 질문

1. 독자가 강사 없이도 어디까지 수행할 수 있어야 하는가?
2. 이 장에서 정의만 알면 되는 것과 원리까지 이해해야 하는 것은 무엇인가?
3. 어떤 실제 사례가 없으면 설명이 추상적으로 남는가?
4. 반드시 다뤄야 할 반례, 실패 조건과 적용 한계는 무엇인가?
5. 장을 읽은 뒤 독자가 다음 Unit을 수행할 준비가 됐는지 어떻게 알 수 있는가?

### 산출물

- Unit에 대응하는 자기완결적 원고
- 인접 출처와 참고문헌
- 사례, 반례와 한계

### 전이 전 사용자 확인

원고의 깊이, 문체, 사례 선택과 독자 자립 수준이 의도와 맞는지 확인한다.

## 05 Materials

### 이 단계에서 읽어야 할 의도

- 강의, 실습, 토론과 평가의 리듬
- 강사가 보여줄 것과 수강생이 직접 할 것
- 자료 매체와 운영 환경
- 수업 중 피드백 방식

### 핵심 유도 질문

1. 이 Unit에서 학습자가 실제로 손을 움직여야 하는 순간은 어디인가?
2. 강사 데모와 수강생 실습 중 어느 쪽이 목표를 더 직접 증명하는가?
3. 실패했을 때 무엇을 보여주면 스스로 원인을 찾을 수 있는가?
4. 슬라이드가 아니라 코드·worksheet·토론이 더 적합한 내용은 무엇인가?
5. 평가 결과만 보고 수행목표 달성 여부를 판정할 수 있는가?

### 산출물

- 필요한 슬라이드·데모·실습·평가
- 강사 가이드와 예상 결과
- 리허설 기록

### 전이 전 사용자 확인

자료가 보기 좋은지를 넘어 실제 수업에서 원하는 수행을 유도하는지 확인한다.

## 06 Deliveries

### 이 단계에서 읽어야 할 의도

- 기관이 해결하려는 업무 문제
- 대상자의 실제 수준과 환경
- 시간·기술·보안 제약
- 표준 과정에서 반드시 유지할 학습성과

### 핵심 유도 질문

1. 표준 대상과 이번 수강생은 무엇이 다른가?
2. 기관이 과정 후 기대하는 업무 변화나 산출물은 무엇인가?
3. 시간 제약으로 무엇을 줄여야 하며 그때 잃는 학습성과는 무엇인가?
4. 기술 스택 변경이 단순 문법 변경인지 개념과 평가까지 바꾸는지?
5. 납품 성공을 누가 어떤 증거로 승인하는가?

### 산출물

- 요구 프로파일
- Unit 선택과 시간표
- adaptation decision
- 최종 배포물과 운영 체크

### 전이 전 사용자 확인

표준 과정의 핵심 수행이 보존됐는지, 기관별 변경과 위험을 수용하는지 확인한다.
