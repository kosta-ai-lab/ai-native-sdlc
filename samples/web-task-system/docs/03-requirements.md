# 03 요구사항 — 할 일 생성 (Task Creation)

> 레퍼런스 앱: 사내 업무 관리 시스템. 첫 기능 "할 일 생성"의 요구사항 단계 산출물입니다.
> 이 문서는 모듈 03(요구사항·유즈케이스)의 산출물이며, 04 SDD의 입력이 됩니다.

## 배경

팀이 업무를 "할 일" 단위로 등록하고 진행 상태를 관리합니다. 가장 먼저 필요한 기능은 할 일을 생성하는 것입니다.

## 유즈케이스 UC-01: 할 일 생성

- 행위자: 팀원
- 목적: 처리할 업무를 할 일로 등록합니다.
- 사전 조건: 없음 (최초 기능)
- 기본 흐름:
  1. 팀원이 할 일 제목을 입력합니다.
  2. 시스템이 할 일을 생성합니다.
  3. 생성된 할 일의 상태는 "할 일"입니다.
- 대안 흐름:
  - 제목이 비어 있으면, 시스템은 "제목은 필수" 오류를 반환합니다.

## 요구사항

| ID | 요구사항 | 유형 |
|----|---------|------|
| R-01 | 제목이 있는 할 일을 생성할 수 있다 | 기능 |
| R-02 | 새 할 일의 초기 상태는 "할 일"이다 | 기능 |
| R-03 | 빈 제목은 거부하고 오류를 반환한다 | 기능(검증) |
